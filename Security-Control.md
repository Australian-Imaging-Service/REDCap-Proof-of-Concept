**Security controls**

✅ TLS for all API communication.

✅ Encryption of stored credentials and masking in the interface and logs.

✅ Separate identities for destinations and inbound clients.

✅ Project-, arm-, event-, instrument-, operation- and field-level validation.

✅ Credential expiry, rotation and revocation.

✅ Audit records for configuration changes, inbound requests and publication outcomes.

✅ Correlation identifiers, rate limiting and request-size controls.
